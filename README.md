# atluriogames.github.io

Static site of Atlurio Games (GitHub Pages, no build step).

- `/`, `/ru/` — home page (EN, RU)
- `/privacy/`, `/ru/privacy/` — Privacy Policy (EN, RU)
- `/delete-account/`, `/ru/delete-account/` — account and data deletion (EN, RU)
- `/app-ads.txt` — authorized sellers for Google AdMob, Unity Ads and ironSource Exchange (ads via Unity LevelPlay); the ironSource reseller list changes from time to time, see the link in the file

The Privacy Policy describes what the game Atlurio: World Geography Quiz actually does:
Unity Gaming Services (anonymous player account, automatic cloud save, Arena) and ads
through Unity LevelPlay (ironSource Ads, Unity Ads, Google AdMob). When the game changes what it
collects, update both languages and the effective date. Google Play Games sign-in is not in the
game yet: add it to section 2 of both policies when it ships.

Look: the game's own brand. The top band uses the app icon's blue, headings use Nunito (the game's
font, `/fonts`), icons in `/img` are made from the game's app icon. No third-party requests: no
external fonts, scripts, cookies or analytics.

`/img/island-1.webp` … `island-5.webp` are real screens of the campaign islands (levels 1 to 5),
cut below the game's HUD so they carry no text in any language. Source: the game repository,
`Captures/Balloon_20261030/look_*.png` (1280x2772 game view), cropped from y = 250 and saved at
400x712, WebP quality 80. When the islands change in the game, take new screens the same way.

Writing on the site follows the game's text rules: no long dashes and no middle dots as separators.
